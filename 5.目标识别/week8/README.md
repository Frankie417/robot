# Week8 手势选色与 P4 物块抓取

本机运行手势识别，Jetson 运行摄像头核色及机械臂控制。通过实验设备的 Micro-USB USB 网络通信。所有 Week8 文件均为新建，原 Week6/Week7 文件不修改。当前只有真机接收端，没有 simulation 模式。

## 手势与颜色

| 手势 | 选择内容 | 确认 |
| --- | --- | --- |
| One 食指 | 红块 → 有害垃圾桶 | 再做 OK |
| Two 食指和中指 | 黄块 → 其他垃圾桶 | 再做 OK |
| Three 食指中指无名指 | 绿块 → 厨余垃圾桶 | 再做 OK |
| Five 张开手掌 | 蓝块 → 可回收垃圾桶 | 再做 OK |

**Five 在 Week8 中只选蓝色，不再承担停止功能。** 停止请点击本机红色“停止当前动作”按钮、按本机窗口的 Esc，或点击 Jetson 面板停止按钮。软件保护停止仍不等于设备物理急停。

映射集中在 `week8_settings.py` 的 `GESTURE_COLOR_MAP`；独立 notebook 则在第一个参数代码单元中。默认顺序为 1红、2黄、3绿、5蓝。

一次操作：P4 放一个物块 → 点击准备下一条 → 摆出选色手势 → 看到候选后做 OK → Jetson 核对 P4 唯一色块是否与请求颜色一致 → 执行抓放。颜色不符、多目标、无物块或相机失效时不会抓取。仅在 Jetson 画面里出现物块不会自动执行。

## 启动顺序

1. 实验箱正常供电，Micro-USB 数据线连接本机与 Jetson。关闭旧 Week6、Week7 或其他占用 Jetson 摄像头/舵机串口的程序。
2. 本机浏览器访问 `http://192.168.55.1:8888`，进入 Jetson 的 JupyterLab。
3. 把 `week8_jetson.ipynb` 上传到 Jetson，新建目录保存即可。运行全部单元，点击“启动 Week8 服务”。启动时检查当前配置并连接 SDK/相机，不自动移动机械臂。
4. Jetson 面板显示地址 `http://192.168.55.1:8766` 和本次 TOKEN。**8766 是 Week8 指令端口，8888 是 Jupyter，原 Week7 的 8765 不能混用。**
5. 本机双击 `start_week8_laptop.bat`。若要用 notebook，需在本机启动 Jupyter，运行 `week8_laptop.ipynb`；不要在 Jetson 的网页内核运行本机手势 notebook。
6. 本机启动摄像头，填入 8766 地址及当次 TOKEN，点击“连接并查询”。
7. 点击“解除停止”，再点击“Jetson回拍摄位”。这一步会真实运动；确认成功后再放置 P4 物块。若刚执行过停止，先清空 P4，让相机连续确认空区。
8. P4 放一个物块，点击“准备下一条”，做对应的 1/2/3/5，再做 OK。每轮只发送一次；下一轮需重新准备。
9. 动作完成后等待机械臂回拍摄位，P4 连续空置 8 帧后再放下一块。若未抓走，接收端等待清空，不自动重复抓取。

本机可先单独打开摄像头观察识别，但未连接时不能发送真实抓取指令。接收服务每次重启都会换 TOKEN；重新连接并复制新令牌。Invalid token 表示服务可达但令牌不匹配。

终端替代入口：将整个模块目录复制到 Jetson 后执行：

```bash
python3 receiver.py --sdk-dir '/home/jetson/Notebook/4.机械臂OpenCV视觉处理实验' --arm-port /dev/ttyTHS1
```

本机已有环境不需要重装。新 Windows 环境可使用 Python 3.11 创建本目录 `.venv` 并安装 `requirements_laptop.txt`。Jetson 不安装本机 MediaPipe 依赖，沿用课程 SDK 环境。

## Five 为什么更容易识别

- Five 模型分数门槛：从 Week7 的 0.70 降到 **0.50**；其他手势仍为 0.70。
- Five 选色确认：从 3 帧减为 **2 帧**；OK 仍需 3 帧。
- 增加四个非拇指的宽松关键点判断，伸直比值 **1.55**；允许拇指不完全伸直，只要没有形成 OK 环。
- 手部检测、存在和跟踪的门槛为 0.45。
- OK 和 Three 的几何判断优先于宽松 Five，避免把它们直接抢判成 Five；检出多手仍拒绝触发。

几何余量分数不是概率。放宽后更容易选中，也可能更容易误选，所以必须看到候选正确后再做 OK；若误选，先重新做正确的选择手势。候选 8 秒超时失效。真实 Five 的准确率仍需你出镜验证。

## 互锁与错误处理

Week8 使用独立接口版本、端口和令牌头，不会把新命令发给旧 Week7 服务。每条命令带唯一编号、会话和指令代次；停止后迟到的旧指令失效。动作运行期间拒绝新动作，只有手动停止能优先进入。

本机持续发送心跳；断连约 1.5 秒后 Jetson 自行取消剩余轨迹并保持当前位置。相机失效同样触发保护。停止请求走独立连接，不排在完整抓取动作后面；动作结果等待上限为 90 秒，避免旧 15 秒超时把完整抓放中途打断。

制停仍有识别、网络、线程调度和舵机响应延迟，不是认证的硬件急停。中断或失败后不自动开爪或回零。恢复前先检查设备，解除停止、回拍摄位，并清空 P4 后再准备。串口或保持反馈失败时会锁定，不能强行续跑。

## 记录与验证

本机记录位于本目录 `results/`，Jetson 记录位于其当前目录 `week8_records/`。日志包含选色、实际检测色、目标桶、阶段、结果和 P4 清空状态；截图在 Jetson 保存触发时的 P4 识别画面。

`done` 表示动作流程返回。返回体的 `p4_clear` 单独说明 P4 是否清空；`actual_bin_observed` 保持 false，桶内实际成功与否需现场观察。未清空时不自动重复抓取。

```powershell
python test_week8.py
```
